# Contributing

## Pull requests

1. Branch from `main` using a short prefix (`fix/`, `feat/`, `docs/`, `ci/`, `chore/`).
2. Keep PRs small (1–3 commits) with a clear why in the description.
3. Ensure GitHub Actions **CI** is green before merge.
4. Prefer merge commits so DevLake can attribute lead time cleanly.

## Incidents

Production incidents should be filed as GitHub Issues with labels `incident`, `bug`, and `production`.
Close them with a short resolution note so DevLake can compute Time to Restore.
